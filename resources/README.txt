《晋曲棋旅》素材目录说明
================================

程序启动时会自动加载本目录下的图片素材（背景、地标照片、戏曲图片）。
想换成自己的照片，把文件放进对应子目录即可生效（不用改代码、不用重新编译）。

目录结构：

  resources/
  ├─ backgrounds/   主界面背景、答题弹窗背景
  ├─ places/        15 个普通地块（山西文化地标）的地域风貌图
  ├─ quiz/          21 张“看图识戏曲”题的图片
  └─ audio/         晋剧配乐与题目音频（WAV / MP3）

支持的图片格式：png / jpg / jpeg / webp / bmp（同名时按上述顺序优先）
支持的音频格式：wav / mp3 / ogg / m4a / flac
  ※ 音频播放依赖 Qt Multimedia 模块（工程文件已声明）；缺少该模块时无法编译。

程序会在以下位置查找 resources 目录（找到即用）：
  1. 可执行文件所在目录
  2. 可执行文件目录的逐级上级目录（最多 5 级，兼容 Qt Creator 的影子构建目录）
  3. 当前工作目录
