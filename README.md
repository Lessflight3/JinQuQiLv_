# 晋曲棋旅 — 晋剧文化主题大富翁（Qt 6 课程设计）

2~4 名玩家掷骰子、买地收租；踩到「晋剧文化地块」时按类别抽题作答，
答对奖励、答错惩罚，直到只剩一名未破产玩家。

## 一、本版亮点

| 项目 | 说明 |
| --- | --- |
| 棋盘比例 | 24 格 = 1 起点 + **15 个山西文化地标** + **8 个晋剧文化地块**（四大类题目各占 2 块） |
| 题库 | **四类共 86 道题**：①晋剧常识 21 ②听曲牌识曲牌 21 ③听唱段识剧目 23 ④看图识戏曲 21 |
| 题目分布 | 开局时四大类**随机散布**到 8 个晋剧地块上（每类 2 块），棋盘格右上角显示类别角标（常识/曲牌/唱段/图片） |
| 界面背景 | 主界面与答题弹窗均为「晋剧舞台 + 山西山水古建」融合背景图 |
| 地域风貌 | 每个普通地块落地时弹出该地标的地域风貌图（悬空寺、壶口瀑布、云冈石窟、平遥古城……） |
| 看图题 | 21 张戏曲元素图片（脸谱、髯口、水袖、翎子、马鞭、晋胡、蟒袍、靠衣、厚底靴……） |
| 配乐 | 进入游戏循环播放晋剧曲牌《小开门》，可一键开关（按钮或按 M 键） |
| 文字排版 | 所有文字按可用空间自动缩放/省略；窗口按屏幕自适应，面板高度不再溢出 |
| 快捷键 | 空格 / 回车 = 掷骰子，M = 开关配乐 |

## 三、构建与运行

**Qt Creator**：打开 `JinQuQiLv.pro` → 选择 `Desktop Qt 6.12.0 MinGW 64-bit` 套件 →
右键工程「执行 qmake」→ `Ctrl+R`。

**工程路径**：放在哪里都能编译。工程内部所有头文件都用**相对路径**包含
（如 `#include "../model/game.h"`），`.pro` 里也不设置 `INCLUDEPATH`，
因此编译命令中不会出现工程绝对路径，放在中文目录下也不会出现
`model/game.h: No such file or directory`。

**命令行（MinGW）**：

```bat
cd /d "C:\Users\lenovo\Desktop\专业课\C++程序设计\The song and journey of Jin"
D:\QT\6.12.0\mingw_64\bin\qmake.exe JinQuQiLv.pro CONFIG+=release
D:\QT\Tools\mingw1310_64\bin\mingw32-make.exe -j4
release\JinQuQiLv.exe
```

**命令行参数（可选）**：

```bat
JinQuQiLv.exe --players 4      :: 跳过开局对话框，直接 4 人开局
JinQuQiLv.exe --selfcheck      :: 启动后自检排版与音频，报告写入 layout_selfcheck.txt
JinQuQiLv.exe --no-music       :: 不自动播放背景音乐
```

## 四、玩法规则

| 规则 | 数值 |
| --- | --- |
| 玩家数量 | 2~4 人 |
| 初始资金 | 3000 元 |
| 骰子点数 | 1~6 |
| **戏班开销** | 每回合开演前支付：25 元起，每过 10 回合 +5 元，上限 120 元；交不出即散班出局 |
| 经过起点补贴 | +100 元 |
| 普通地块 | 15 个山西文化地标，售价 120~260 元，租金约为售价的 **60%** |
| 连片加成 | 地主每多持有一块地，名下所有地块租金 **+25%** |
| 晋剧文化地块 | 8 个，四类题目各占 2 块，答对 **+100** 元、答错 **−150** 元 |
| 破产条件 | 现金不足以支付租金 / 答题罚款 / 戏班开销，出局后名下地产重新待售 |
| 获胜条件 | 场上只剩 1 名未破产玩家 |

> 经济参数经过对局模拟调优（2/3/4 人局各 200 局 × 3 种答题水平，**结束率均为 100%**）。
> 4 人局中位出手次数：每题都答对 200 次、一半答对 126 次、每题都答错 91 次；
> 按每次出手（含骰子动画与弹窗）约 7~8 秒估算，一局约 **11~26 分钟**，
> 既不会「半小时打不完」，也不会「还没买地就结束」。

## 五、题目设计原则

`听唱段识剧目` 类改为**唱词片段 / 剧情线索**两种提问方式，`听曲牌识曲牌` 只给音乐特征与
使用场景，`看图识戏曲` 只给画面描述。86 道题逐题把正确选项与题干做子串比对。

## 七、测试与自检

**界面排版自检**（程序内置，随时可复现）：

```bat
JinQuQiLv.exe --players 4 --selfcheck --no-music
```

程序会遍历主窗口中的全部可见控件，比较实际尺寸与所需最小尺寸，同时盘点题目音频是否齐全，
结果打印到控制台并写入 `layout_selfcheck.txt`。本机实测结果：

```
SELFCHECK window=1640x959 widgets=24 problems=0
BOARD size=1194x876 cell=125px 格子数=24
BOARD 最小可用字号=20px（格23「洪洞大槐树」） -> 文字不会被裁切
CENTER 标题牌=525x200 标题=495x104 副标题=495x79 图例行高=56 重叠=0 -> 文字互不重叠
AUDIO 题目音频就绪 35 个 ... 缺失 0 个
```

**手动功能自检清单**（改完代码建议过一遍）：

| # | 操作 | 预期结果 |
| --- | --- | --- |
| 1 | 开局选 2~4 人 | 每人 3000 元，棋子都停在起点 |
| 2 | 掷骰子 | 棋子逐格移动；日志显示点数，经过起点时 +100 元 |
| 3 | 停在无人空地 | 弹出购买窗口，含该地标风貌图、售价与租金；买下后扣钱、格子出现归属角标 |
| 4 | 另一位玩家踩到该地 | 弹出风貌图并结算租金，地主现金相应增加 |
| 5 | 停在晋剧地块 | 弹出答题窗口，类别与格上角标一致；曲牌/唱段题自动播放音频，配乐暂停、答完从断点续播 |
| 6 | 答对 / 答错 | 分别 +100 / −150，并显示正确答案与知识卡解析 |
| 7 | 现金不足支付 | 该玩家破产出局，名下地产回到待售状态 |
| 8 | 场上只剩一人 | 弹出胜利结算窗口 |
| 9 | 按 M 键 | 背景配乐开关切换 |
